# PhishFlow AI

An explainable phishing URL analysis and security automation project.

## Objectives

- Analyse URL characteristics without opening suspicious links.
- Build explainable, rule-based detection.
- Explore phishing datasets and evaluate a classifier using KNIME.
- Generate evidence-based AI investigation summaries.
- Automate analysis and review workflows using n8n.

## Project Status

Phase 1: Environment setup and Python foundations.

## Safety

This project is intended for defensive security research and educational use.
Suspicious URLs are treated as data and are not automatically visited.
